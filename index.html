🔍 What is Git & GitHub?

Git is a version control system that helps you track changes in your code. GitHub is a cloud platform where you can store and share your Git repositories online.

In this assignment, you will maintain separate branches for each Use Case (UC) and merge them into a develop branch using Pull Requests.

🌿 Branch Structure Overview
main
The production branch. Stable, final code only.
develop
The integration branch. All use cases merge here.
feature/uc1, uc2…
Individual use case branches. One per use case.
⚙️ Phase 1 Initial Repository Setup
Do this ONCE
1
Create a Repository on GitHub
Go to github.com→ Click '+' icon→ New repository→ Name it→ Keep Public→ NO README→ Create repository
📋Copy the repository URL shown on the next page — you'll need it in Step 5.
2
Create a local folder & open Terminal

Create a new folder on your computer. Open Terminal (Mac/Linux) or Git Bash (Windows) and navigate to it:

cd path/to/your/folder
3
Initialize Git in your local folder
git init
💡This creates a hidden .git folder — this is how Git tracks your files.
4
Stage & Commit initial files

Even if the folder is empty, do an initial commit:

git add . git commit -m "initial message"
5
Link your local folder to GitHub
git remote add origin https://github.com/your-username/your-repo.git
💡Replace the URL above with your actual GitHub repository URL.
6
Create & push the main branch
git checkout -b main git push origin main
7
Create & push the develop branch
git checkout -b develop git push origin develop
✅ Setup Complete — You now have main and develop on GitHub!

1
Create feature branch for UC1
git checkout -b feature/uc1
💡Creates feature/uc1 from develop and switches to it.
2
Write your code for Use Case 1

Write all your code files for UC1. Do NOT commit yet.

3
Stage all your changes
git add .
💡The dot . means "add all changed files". Make sure you're in the project folder.
4
Commit with a message
git commit -m "uc1 completed"
5
Push the branch to GitHub
git push origin feature/uc1
6
Create a Pull Request on GitHub
🌐In your browser:
Open repo→ Compare & pull request→ base: develop→ compare: feature/uc1→ Create PR→ Merge & Confirm
7
Switch back to develop & pull latest
git checkout develop git pull origin develop
✅ UC1 is complete and merged into develop!

📚 Quick Command Reference
Command
What it does
git init
Initializes a new Git repository in current folder
git add .
Stages all changed files for the next commit
git commit -m "message"
Saves a snapshot of your staged files with a message
git remote add origin <url>
Links your local repo to GitHub
git checkout -b <branch>
Creates a new branch and switches to it
git push origin <branch>
Uploads a branch to GitHub
git checkout <branch>
Switches to an existing branch
git pull origin <branch>
Downloads and merges latest changes from GitHub
